# Verses

The curated list of the [Bible Verse Widget](https://github.com/TechnikWeber/bible-verse-widget):
1000 verses in three translations, all in the public domain (Luther 1912, World
English Bible, Reina-Valera 1909). RadioKiosk picks the verse of a day by the
same rule as the widget, so both show the same one.

The Herrnhuter Losungen are not here and must not be: they are free of charge
for non-commercial use, but not free content. Download the year file yourself
from <https://www.losungen.de/digital/> and import it in the settings.
